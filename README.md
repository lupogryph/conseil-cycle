# Conseil de cycle

Front application that provide a login page, user profile and a simple dashboard which consist of a shared calendar where users can create events with date and location, shared to see for all users

The admin can see more information than regular users, like who created an event and who edited an event

The name of the project reflects its primary usage, which was to provide a simple app for teachers of schools in an area to meet themselves regularly

The Backend is [conseil-cycle-api](https://github.com/lupogryph/conseil-cycle-api)

Angular 18
